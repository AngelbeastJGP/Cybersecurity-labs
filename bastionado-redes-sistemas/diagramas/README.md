# Diagramas

Ilustraciones generadas para representar las topologías y los flujos descritos
en las prácticas. Se revisaron las conexiones, los nombres y las direcciones
antes de incorporarlas. Son esquemas explicativos, no capturas de la ejecución:
las comprobaciones originales siguen en `../evidencias/` y los parámetros
completos en las tablas y configuraciones de cada práctica.
