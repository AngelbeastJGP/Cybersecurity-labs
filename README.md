# Cybersecurity Labs

Repositorio de laboratorios prácticos de ciberseguridad realizados en entornos
locales y controlados.

## Objetivo

Documentar prácticas técnicas con un enfoque profesional: qué se quería montar,
qué decisiones se tomaron, qué problemas aparecieron y cómo se verificó el
resultado final.

## Laboratorios

| Área | Descripción |
| --- | --- |
| [Bastionado de redes y sistemas](bastionado-redes-sistemas/) | Infraestructuras virtuales, segmentación, servicios internos, control de accesos y preparación para hardening. |
| [Lab setup](lab-setup/) | Notas de preparación de entornos de laboratorio. |

## Buenas prácticas de publicación

- No se publican contraseñas, claves privadas, tokens ni datos personales.
- Las capturas se usan como evidencias, no como sustituto de la explicación.
- Los ejercicios basados en material de estudio se documentan con redacción
  propia y sin copiar enunciados completos.
- Cada laboratorio incluye comprobaciones técnicas y problemas encontrados.
